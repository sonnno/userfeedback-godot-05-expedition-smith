# 远征铁匠（Expedition Smith）

使用 **Godot 4.7.2** 开发的 2D 制作经营游戏。玩家为三名士兵锻造武器，再观看队伍自动出征；武器的制作质量、材料与附件会真实影响战斗表现。支持鼠标 + 键盘操作，全部画面由代码自定义绘制，无需外部素材。

## 运行方法

1. 用 Godot 4.7.2 打开本项目目录（`project.godot` 所在目录）。
2. 按 **F5**（或点击右上角运行）即可开始。
3. 主场景：`res://scenes/main.tscn`；全局状态自动加载：`res://scripts/game.gd`。

无需安装插件或导入资源，中文字体自动回退到系统常见字体（微软雅黑/黑体/PingFang/Noto 等）。

## 玩法与规则

### 一局节奏
- 一局共 **三天**，每天三名士兵（先锋 / 盾卫 / 游侠）各下一张订单。
- 每天提供 **铜、铁、钢各 3 份**，每件武器消耗 1 份材料。
- 三件武器全部交付后才能出征；第三天战斗结束后显示三天总结。

### 武器制作（三道可操作工序）
1. **浇铸**：按住鼠标左键（或空格）注入熔液，松开停止。填充停在 90% 附近（85%~95%）满分；超过 100% 满溢会大幅降质。
2. **锻打**：刀坯上依次出现 5 个发光目标点，鼠标点击，越靠近圆心得分越高，每个点只记分一次。
3. **装配**：先选择附件，再拖动手柄对准刀身插槽松开（也可用方向键移动、回车释放），释放位置越准分越高。

三道工序各 0~100 分，**总质量为三者平均分**。交付界面展示各工序得分、成品属性与订单匹配情况。

### 订单匹配
- 类别（剑/斧）或材料不符订单：**有效质量减半**。
- 附件选错：**没有附件加成**。
- 每张订单只能交付一次。

### 出征战斗
- 侧视场景队伍自动推进，依次与 **三组怪物** 交战；双方优先攻击最前方存活单位。
- 士兵每秒攻击一次，**同一时刻的伤害同时结算**。
- 士兵初始生命 100。
- 武器实际攻击 = 材料基础攻击 ×（0.5 + 有效质量/100）；铜/铁/钢基础攻击为 **10 / 14 / 18**。
- 武器耐久 = 10 + 有效质量/5（向下取整），每次攻击耗 1 点；耗尽后改为 **2 点徒手攻击**。
- 攻击附件符合需求 +3 攻击；耐久附件符合需求 +10 耐久。
- 每组 3 只怪物，生命与伤害随天数上升。
- 士兵全灭则当天失败（**同归于尽也算失败**）；清空三组为当天胜利。失败也能进入下一天，次日士兵恢复满血。
- 每击败一组得 10 金币，当天全胜额外得 10 金币。

### 工具升级
- 次日休整界面可各花 **20 金币** 升级锻打或装配工具，每项限一次。
- 升级后扩大对应工序的满分判定范围（锻打命中圈 16px→26px；装配对准距离 14px→24px）。

## 操作速查

| 操作 | 鼠标 | 键盘 |
| --- | --- | --- |
| 浇铸注入 | 按住左键 / 松开停止 | 按住空格 / 松开停止 |
| 锻打 | 点击目标点 | — |
| 装配拖动手柄 | 按住拖动、松开释放 | 方向键移动、回车释放 |
| 查看订单 | 点击「订单」按钮 | I |
| 暂停 / 关闭弹层 | 按钮 | Esc |
| 界面按钮 | 点击 | Tab 切换 + 回车 |

暂停会冻结制作与战斗；重新开始会清空订单、材料变化、工具升级与全部成绩。

## 代码结构

```
scripts/
  main.gd               根节点：场景路由、全局主题、暂停控制
  game.gd               自动加载单例：局内状态、订单生成、武器数值公式
  ui.gd                 通用卡通风格 UI 构建工具
  h_bar.gd              水平数值条（生命/耐久/进度）
  weapon_icon.gd        成品外观（区分类别/材料/附件）
  main_menu_screen.gd   主菜单（新游戏/操作提示/退出）
  workshop_screen.gd    工坊主界面（订单栏 + 工序区 + 订单弹层）
  setup_view.gd         开工设置（类别/材料选择与库存、不符警告）
  casting_game.gd       浇铸工序
  forging_game.gd       锻打工序
  assembly_game.gd      装配工序（附件选择 + 拖动手柄）
  delivery_view.gd      交付展示（得分/属性/匹配）
  battle_field.gd       战场自定义绘制控件
  battle_screen.gd      出征战斗（推进、同时结算、飘字、状态卡）
  interlude_screen.gd   日间隔夜（战报 + 工具升级）
  final_screen.gd       第三天总结
  help_overlay.gd       操作提示与玩法说明
  pause_overlay.gd      暂停菜单（继续/提示/重启/主菜单）
scenes/main.tscn        主场景
```
